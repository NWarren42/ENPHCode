CMPE/CISC 457 Assignment 2

Due October 31 at NOON.

In this assignment, you will implement code to

  (a) implement 1D inverse FFT and 2D forward and inverse FFTs
  
  (b) edit the Fourier Transform of an image by increasing or
      decreasing magnitudes of complex Fourier coefficients that you
      click on.

1. Get the code compiling and running.  For Linux and MacOS, see the
   README.txt files.  For Windows, click on the project file.  Run the
   code as

     ./conv ../images/clown.png ../filters/gaussian3

   Press '?' with the mouse in the program window to have a list of
   commands printed in the terminal window.  Apply the Fourier
   Transform to several of the images to see what appears in the
   spectral domain.

2. Read compute.h and compute.cpp and understand how this works.
   Understand very clearly the classes in compute.h.

3. Modify the functions in compute.cpp according to the comments in
   that code at "[YOUR CODE HERE]".

4. Denoise as best you can the canvas, moon, and mariner6 images using
   editing in the Fourier domain.
